## 2. Restore locally

```bash
# 1. Unzip
unzip MARU-GHAR-MASTER-BACKUP-21-NOV-2026.zip
cd Maru-Ghar          # or whatever the top folder is named

# 2. Confirm you are on the right commit
git log -1 --format='%H %s'
# 2271058bf8cabfb9ed497089212b9da18b7e1fc3 is the last application-code commit;
# any commits above it only add MASTER-PROJECT-STATUS.md / RESTORE-GUIDE.md

git status --short        # should be clean

# 3. Install dependencies (Node 22+ recommended)
node -v                   # v22.x or newer
npm ci

# 4. Install the browser used by the swipe test
npx playwright install --with-deps chromium

# 5. Regenerate the www mirror from source
npm run copy-web

# 6. Run the full suite
npm test
```

### Expected result

All 16 scripts pass, ending with:

```
Android swipe check: all assertions passed
```

If `swipe-check.mjs` cannot find a browser, set one explicitly:

```bash
MG_CHROME_PATH=/path/to/chrome npm test
```

The script also auto-discovers Playwright's cached Chromium, a system Chrome, and
the AppJet sandbox paths — `MG_CHROME_PATH` is only needed when all of those fail.

### Useful single commands

```bash
npm run test:swipe    # swipe check only
npm run copy-web      # source -> www
npm test              # everything
```

## 9. Android and desktop builds

**Android** — there is no committed `android/` folder:

```bash

npx cap add android      # first time only
npx cap sync android
npx cap open android     # or build in CI
```

The `android-apk.yml` workflow generates and builds the APK automatically.
Capacitor updater v7 powers the OTA path; the manifest is HTTPS and pinned to
Firebase Hosting, and updates apply at next launch — never during active use.

**Desktop** — Electron 43:

```bash
npm ci
npm run desktop:win      # electron-builder --win nsis --x64 --publish never
```

`windows-exe.yml` runs this on pushes to `main`. It has **not** been exercised
with Electron 43 yet, so treat the installer build as unverified until that
workflow runs.

## 11. Quick troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `Cannot find module 'playwright'` | Dependencies not installed | `npm ci` |
| Swipe test cannot launch browser | No Chromium available | `npx playwright install --with-deps chromium`, or set `MG_CHROME_PATH` |
| `www` out of sync failure in smoke check | Source edited without regenerating | `npm run copy-web` |
| `npm ci` fails on electron entries | Old lockfile | Use this snapshot's `package-lock.json`, or `npm install` once |
| Firestore rules check fails | Rules edited | Re-read `final-firestore-rules-check.mjs` expectations — fix the rule, not the test |
| Workflow passes locally, fails in CI | Environment-specific path assumption | Never hardcode sandbox paths; resolve tools portably |
